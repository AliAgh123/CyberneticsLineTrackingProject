If I understand correctly, you want a curve that *looks like* the graph of
[
y = x^2
]
but whose shape “wiggles” with a sinusoidal pattern.

You already have

[
x(t) = 2\sin(2\pi t + \pi/2)
]

and you suggested something like
[
y = x^2
]

### ✔️ Option 1 — Simply use the sinusoid inside the squared function

Then the parametrized curve is:

[
x(t) = 2\sin(2\pi t + \pi/2)
]
[
y(t) = [,x(t),]^2 = 4\sin^2(2\pi t + \pi/2)
]

This gives a **sinusoid but always positive** (because of the square).
It looks like a “wiggly parabola” but it does *not* grow like (x^2); it stays between 0 and 4.

If you want the **shape of x² with oscillations**, keep reading.

---

### ✔️ Option 2 — A parabola with sinusoidal modulation

If you want something shaped like ( y = x^2 ) but vibrates up and down, do:

[
y(x) = x^2 \Big(1 + A \sin(\omega x)\Big)
]

Here

* (A) controls the wiggle amplitude
* (\omega) controls how fast it wiggles

Example:

[
y(x) = x^2\big(1 + 0.2\sin(5x)\big)
]

This is literally a parabola with ripples.

---

### ✔️ Option 3 — Parametric form combining both ideas

If you want to keep *your sinusoidal x(t)* but make y(t) look like a parabola modulated by a sinusoid:

[
x(t) = 2\sin(2\pi t + \pi/2)
]
[
y(t) = x(t)^2\big(1 + A\sin(\omega t)\big)
]

Example:

[
y(t) = x(t)^2\big(1 + 0.3\sin(10t)\big)
]

This gives a wiggle in both *x* **and** *y*.

---

### ✔️ If what you want is *a sinusoid following the shape of a parabola*

Then use:

[
y(x) = x^2 + A\sin(\omega x)
]

Example:

[
y(x) = x^2 + 0.5\sin(10x)
]

This is the most common interpretation of “a parabola with a sinusoidal shape”.
